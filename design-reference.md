# Robocode XR — візуальний стиль і дизайн-референс

Дата фіксації: 23 листопада 2026 року.  
Джерело: наданий скриншот екрана введення ключа, 2500 × 1484 px.  
Призначення: зберегти візуальну основу для вебкабінету викладача, адмінпанелі, лендингу та подальших екранів гри.

## 2. Що видно на зображенні

Стиль мінімалістичний, ігровий і виразний: великі кольорові площини, округлені елементи, небагато тексту та одна помітна основна дія. Інтерфейс має характер окремої ігрової панелі з контуром і виступаючою кнопкою.

- **Фон:** суцільний темно-сірий, графітовий.
- **Основна панель:** великий яскраво-синій прямокутник із заокругленими кутами та світлішим синім контуром.
- **Заголовок:** білий, без зарубок, звичайної насиченості; розташований по центру над полем.
- **Поле введення:** широке, світло-сіре, з дуже округленими кутами та світлим сіруватим контуром. Підказка всередині сіра й курсивна, вирівняна ліворуч.
- **Основна кнопка:** яскраво-зелена, капсульної форми, з великим жирним темним синьо-зеленим написом `Enter`.
- **Розташування кнопки:** праворуч унизу; кнопка виступає за нижню межу панелі та оточена графітовим відступом. Контур синьої панелі огинає цю ділянку.
- **Декор:** контурні акценти й легке візуальне підсилення країв. Фактур, ілюстрацій та іконок на цьому екрані немає.
- **Композиція:** багато вільного простору; заголовок і поле утворюють центральну вісь, а кнопка зміщена до правого нижнього кута.

## 3. Палітра

HEX-значення взято з пікселів збереженого JPEG. Великі однорідні ділянки дають стабільні значення; краї й текст мають варіації через згладжування та стиснення. Це палітра референсу, а не підтверджені значення з Unity-матеріалів.

| Роль | HEX для подальшої роботи | Спостереження |
|---|---|---|
| Основне темне тло | `#303030` | Стабільний колір фону; також використовується навколо кнопки |
| Світле тло вебінтерфейсу | `#F5EFED` | Суцільне тепле сіро-біле тло адмінпанелі та світлих екранів |
| Основний синій | `#1646FE` | Стабільний колір заливки великої панелі |
| Синій контур | `#0F75FF` | Орієнтир зі світлішої частини контуру; на краях є кілька відтінків |
| Зелений акцент | `#34F882` | Домінантний колір внутрішньої площини кнопки |
| Світла поверхня поля | `#EFEFEF` | Стабільний колір заливки поля |
| Контур поля | `#D1DAD9` | Орієнтир світлого сіро-зеленого контуру |
| Текст на синьому | `#FFFFFF` | Нормалізований білий; у JPEG пікселі тексту мають невеликі відхилення |
| Текст кнопки | `#004D64` | Орієнтир темного синьо-зеленого кольору напису |
| Темний бірюзово-зелений | `#023436` | Глибокий темно-зелений відтінок для тексту й акцентів на світлому та зеленому тлі |
| Текст підказки | `#B3B3B3` | Орієнтир сірого кольору placeholder |

Співвідношення кольорів у референсі: синій займає основну площу, графітовий обрамляє екран, світло-сірий виділяє введення, зелений акцентує дію. Не варто трактувати яскравий зелений лише як колір статусу «успіх»: тут він уже виконує роль основної кнопки.

## 4. Форми, пропорції та типографіка

Орієнтовні виміри саме цього скриншота:

| Елемент | Спостереження |
|---|---|
| Синя панель | Близько 85% ширини зображення; широкі зовнішні поля |
| Кути панелі | Помірне округлення, приблизно 30–35 px на скриншоті |
| Контур панелі | Помітний, приблизно 6–8 px разом із переходами краю |
| Поле введення | Приблизно 910 × 130 px; близько 43% ширини панелі |
| Кути поля | Сильно округлені, приблизно 55–65 px |
| Кнопка | Приблизно 335 × 125 px, капсульна форма |
| Текст | Заголовок середньої насиченості, підказка курсивна, основна дія жирна |

Ці розміри описують пропорції референсу, а не готові CSS-розміри. На вебі їх потрібно адаптувати до щільності інформації та ширини екрана.

Точну гарнітуру зі скриншота встановити неможливо. Для реалізації потрібен читабельний шрифт без зарубок із підтримкою української кирилиці та звичайним, курсивним і жирним накресленнями. Остаточний вибір шрифту залишається відкритим.

## 5. Пропозиції для вебінтерфейсів

Цей розділ містить рекомендації для майбутньої розробки, а не елементи, вже показані на скриншоті.

### Екран входу

- Зберегти синю панель, світле округлене поле, білий заголовок і зелену основну дію.
- Для учнів використати формулювання «Введіть PIN-код класу» та кнопку «Увійти».
- Додати помітну другорядну дію «Вхід для викладача» відповідно до плану функціональності.
- На широкому екрані можна зберегти кнопку біля правого нижнього краю панелі; на вузькому — розмістити її під полем без перекриття вмісту.
- Додати постійний підпис поля; placeholder не повинен бути єдиним поясненням.

### Кабінет викладача та адмінпанель

- Використати той самий синій (`#1646FE`) для другорядних акцентів, індикаторів, прогресу та фонового графіка динаміки ліцензійних місць.
- Зелений (`#34F882`) залишити для ключових дій на кшталт «Створити нову ліцензію», «Зберегти зміни», активного пункту меню та логотипа `XR`.
- Червоний (`#C8233C`) використовувати для акцентної картки «Завершуються скоро» та статусу припиненої ліцензії «Видалена» в архіві.
- Тепле сіро-біле тло `#F5EFED` доповнюється ледь помітним повільно обертовим фоновим градієнтом, а всі функціональні блоки виконані у вигляді напівпрозорого матового скла (`backdrop-filter: blur(20px)`).
- Зберегти округлені картки та поля, але зробити їх компактнішими, ніж у грі.
- Нижній підпис у футері — `Robocode XR 2026`.
- Статуси учнів і ліцензій позначати текстом та, за потреби, іконкою.

### Лендинг та інші екрани гри

- Для головного промоблоку доречне поєднання великої синьої площини, графітового оточення, білого заголовка та зеленої кнопки.
- У грі можна повторювати контурні панелі, округлені поля та виразні кнопки в меню й діалогах.
- Між вебом і грою зберігати палітру та ієрархію дій, адаптуючи розміри й компонування до конкретного пристрою.

## 6. Початкові змінні кольорів

Нижче — стартові значення для прототипу. Вони не визначають готові стани hover, focus, disabled або кольори повідомлень.

```css
:root {
  --rc-bg-dark: #303030;
  --rc-bg-light: #f5efed;
  --rc-brand-blue: #1646fe;
  --rc-brand-blue-outline: #0f75ff;
  --rc-action-green: #34f882;
  --rc-input-bg: #efefef;
  --rc-input-border: #d1dad9;
  --rc-text-on-blue: #ffffff;
  --rc-text-on-green: #004d64;
  --rc-dark-teal: #023436;
  --rc-alert-red: #c8233c;
  --rc-placeholder-reference: #b3b3b3;
}
```

Перед використанням у готовому вебінтерфейсі потрібно перевірити контраст тексту, placeholder і станів фокусу. Світлий placeholder зі скриншота зафіксований як спостереження; для робочої форми його може знадобитися затемнити.

## 7. Що ще потрібно визначити

- Остаточний шрифт і шкалу розмірів тексту.
- Світлу або темну основу для таблиць і робочих екранів.
- Стани кнопок і полів: наведення, фокус, натискання, помилка, блокування та завантаження.
- Окрему палітру навчальних статусів і системних повідомлень.
- Правила адаптації до мобільних екранів, набір іконок та відступи.

Цей файл фіксує візуальний напрям; деталізація компонентів виконується під час розробки макетів.
