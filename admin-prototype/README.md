# RobocodeXR Admin — інтерактивний прототип

[Файл Figma](https://www.figma.com/design/4yAt59Gao7ckNwbq7bbsK8?node-id=4-11)

[Запустити інтерактивний прототип](https://www.figma.com/proto/4yAt59Gao7ckNwbq7bbsK8?node-id=4-11&starting-point-node-id=4%3A11&scaling=contain&content-scaling=responsive)

Адаптивний прототип панелі адміністратора українською мовою. Імпортований у Figma як інтерактивний Code layer. У файлі також створені нативні змінні кольорів, іконки та базові компоненти інтерфейсу.

## Функціональність

- П’ять демонстраційних ліцензій; скорочені email у списку, повні — під час редагування.
- Окрема форма створення та редагування, видалення з підтвердженням.
- Назва школи: обов’язкова, максимум 50 символів.
- Email: обов’язковий, перевірка формату та дублювання у поточному списку.
- Квота: ціле число від 1 до 100.
- Тривалість ліцензії в днях: випадаючий список із патернами (`10 днів`, `1 міс.`, `3 міс.`, `6 міс.`, `1 рік`, `2 роки`, `3 роки`, `Безстроково`) та двостороннім автоматичним перерахунком із датою завершення.
- Дата завершення: ручне введення, календар із перемиканням місяців або значення `Безстроково`; під час вибору конкретної дати в календарі поле тривалості автоматично показує точну кількість днів від поточної дати.
- Правило завершення: ліцензія з кінцевою датою діє включно протягом обраного дня та завершується о **00:00** наступного дня; безстрокова ліцензія не має обмеження за датою.
- Дашборд, сповіщення, навігаційний шлях, повернення та демонстраційний вихід.
- Сайдбар розгортається та згортається; на телефоні відкривається висувне меню.
- На вузьких екранах таблиця перетворюється на картки.

## Обмеження прототипу

Дані зберігаються в пам’яті поточної сторінки й скидаються після перезавантаження. Немає підключення до реального whitelist, сервера, пошти або Steam. Дата демонстрації зафіксована: **23.11.2026**. Перевірки доступу та ліцензій у готовому продукті мають виконуватися сервером.

## Візуальні рішення

- Суцільний світлий сіро-білий фон `#F5EFED` без ефектів кольорового підсвічування.
- Усі функціональні блоки — напівпрозоре матове скло (`backdrop-filter: blur(20px) saturate(140%)`, нейтральна біла напівпрозорість і тонка межа) без свічення та кольорових градієнтів.
- Зелений `#34F882` використовується для головної дії, активного пункту навігації та бейджів місць; акцентний синій `#1646FE` — для аватару, індикаторів, прогресу та посилань.
- Шрифт Manrope з українською кирилицею; системний fallback за відсутності мережі.
- Основний макет — ноутбук; перелаштування навігації до 1150 px, карток до 900 px, мобільного меню до 700 px.

## Локальний запуск

```sh
npm install
npm run dev
```

Або використайте будь-який статичний HTTP-сервер із коренем у цій папці: прототип не потребує компіляції для перегляду. Синтаксис JavaScript та граничні випадки валідації перевірені окремо.

## Перевірено

- У Figma: помилки порожньої форми, некоректний email, квота 101, вибір дати, створення шостої ліцензії, зміна її квоти з 30 на 40 та видалення з поверненням списку до початкових п’яти записів.
- Локально: адаптивні макети на ширинах 390, 1024 та 1440 px; мобільна форма та панель сповіщень.
- Граничні перевірки: назви довжиною 50/51 символ, email, квоти 1/100/101, дробові й нечислові значення, неіснуючі та минулі дати.
